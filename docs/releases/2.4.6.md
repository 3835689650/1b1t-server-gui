# 1b1t Server 2.4.6（图形版）

## 2.4.6 — 导入本机已有服务器
- 扫描 ~/1b1t-servers、~/servers、~/minecraft-servers、桌面/文档/下载等位置，识别版本（logs/latest.log → version_history.json → forge/neoforge 依赖目录）、类型、端口、EULA、是否在运行（lsof + 90s 日志窗口）
- 导入后写入 .1b1t-open-server/config.json 并注册，即可启动/停止、看实时日志、发控制台指令、改属性、跑自检
- 日志读取回退：没有本程序 console.log 时直接读服务器自己的 logs/latest.log

## 2.4.5 — 本机自适应
- 探测 CPU / 物理与可用内存 / 磁盘余量 / 已装 Java / 空闲端口 / 已有服务器目录
- 按 MC 版本匹配 Java（1.20.5+ → 21、1.18–1.20.4 → 17、1.17 → 16、≤1.16.5 → 8），缺失自动下载
- 修复：1.21+ 被误判为 Java 17；macOS 可用内存只算 free pages
